# 📖 About Project | درباره پروژه

## 🇬🇧 English

BorBor is a modern and responsive school management platform designed for schools in Iran.  
The system helps administrators manage attendance, students, licenses, reports, analytics, and school operations from a single dashboard.

The landing page is built with:
- Pure HTML
- Modern CSS
- Vanilla JavaScript
- Responsive UI/UX
- Glassmorphism & modern dashboard design

---

## 🇮🇷 فارسی

بوربور یک سامانه مدرن و واکنش‌گرا برای مدیریت مدارس ایران است.  
این سیستم به مدیران مدارس کمک می‌کند تا حضور و غیاب، دانش‌آموزان، لایسنس‌ها، گزارش‌ها و عملیات مدرسه را از طریق یک داشبورد یکپارچه مدیریت کنند.
